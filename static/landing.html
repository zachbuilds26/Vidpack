How it works

Three steps, about a minute.

Each step writes to a local database, so the second run on a niche costs nothing and the library keeps growing.

Research

Name a niche and a window. vidpack pulls up to 30 recent videos through the official YouTube API, then scores each one on likes and comments per view, weighted for recency.

Understand

Every title is classified into hook patterns — listicle, how-to, question, comparison, curiosity. Keywords are weighted by the engagement of the videos that use them.

Package

Get five title variants with a CTR estimate, a timestamped script, a description, twelve tags and three thumbnail concepts. Copy any part, or export the JSON.

Patterns

See the pattern, not the vibe.

A niche is not a mystery. The same handful of hook shapes carry most of the top videos, and you can read the split before you write a word.

  • Hook mix — what share of the cohort uses each pattern.
  • Weighted keywords — terms ranked by the performance of the videos using them, not raw frequency.
  • Cohort profile — the duration band most of the winners sit in, and the posting day with the best average engagement.

Questions

The honest answers.

Does this scrape YouTube?

No. Every request goes through the official YouTube Data API v3 — more reliable and less intrusive than scraping.

Is the CTR estimate real?

It is an estimate, and we label it as one. It comes from the hook pattern and the cohort, not from your channel's history. Treat it as a way to rank the variants against each other, not as a forecast.

What do I need to run it?

Point it at a niche, it does the rest. Data is pulled through the official YouTube API and stored in a local SQLite file — everything lives on your machine.

What does "the library compounds" mean?

Every run stores its videos, hooks and packages. Re-pull the stats later and the hooks re-rank against the new numbers, so a hook that keeps performing rises on its own and one that faded drops.

Will this write the video for me?

It writes a first draft with the right structure and the right hook. The judgement, the delivery and the actual expertise are still yours — a script that follows the cohort will not save a video that has nothing to say.
